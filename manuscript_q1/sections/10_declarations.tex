\section*{Statements and Declarations}

\subsection*{Funding}
This research received no external funding.

\subsection*{Competing Interests}
Both authors declare that they have no financial or non-financial competing interests relevant to this work.

\subsection*{Data Availability}
The retained metadata, derived analysis tables, and artifact manifests supporting this study are maintained in the project repository. A versioned public replication release is being prepared before submission. A publicly accessible release URL and persistent identifier are not yet available; the deposited version, access link, and any exclusions must be specified in the final submission. This draft therefore does not claim that the supporting data are already publicly accessible.

\subsection*{Code Availability}
The project repository contains the collection and analysis scripts, numerical consistency checks, figure-generation scripts, and manuscript sources. These materials are intended to accompany the public replication release described above. Reproducing the retained-graph analyses requires the archived observations; repeating live API requests may return different metadata.

\subsection*{Ethics and Consent}
The study analyzes public software-ecosystem metadata and does not involve recruited human participants, interventions on individuals, or execution of package payloads. No participant consent was collected. Usernames are used as observed graph identifiers, without inferring misconduct or present-day account security. The prospective observations contain no measured incident outcomes at the time of this manuscript.
