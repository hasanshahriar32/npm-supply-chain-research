\section{Audit Methodology}
\label{sec:method}
\subsection{Inputs and Independent Reconstruction}
The study uses a compressed metric CSV and SQLite archive supplied together. The database contains 25,228 packages, 22,340 package-version rows, 12,217 maintainers, 79,405 package--maintainer relations, 121,885 dependency rows, and 153,488 advisories. High-impact seeding and dependency discovery produce a convenience sample, not an npm census. The audit date, 20 October 2026, is distinct from collection time.

The offline audit extracts SQLite temporarily and opens it read-only. It verifies package uniqueness and equal populations, derives maintainer portfolios, projects dependency edges onto package-name pairs, and traverses reverse edges with duplicate suppression. The starting package is excluded even in cycles. Workflow flags and all seven metrics are reconstructed independently of the production program. Integer values are compared exactly and database scores at absolute tolerance $10^{-12}$.

CSV scores have six decimal places. Cross-artifact comparisons therefore use tolerance $5.00001\times10^{-7}$ and separately compare database scores rounded to six decimals. Input hashes, code, and aggregate results are retained in the audit record. No package is installed, payload retrieved, or source archive modified.

\subsection{Queues, Ties, and Sensitivity}
For budget $K=\lceil0.01|P|\rceil=253$, let $Q_K^A(f)$ denote the top-$K$ set under field $f$ in artifact $A$. Scores descend; ties use ascending Unicode code-point package-name order. We report intersection and Jaccard overlap,
\begin{equation}
J(Q,Q')=\frac{|Q\cap Q'|}{|Q\cup Q'|},
\end{equation}
and repeat with descending names. These comparisons measure consistency rather than security effectiveness.

If $a$ packages exceed the boundary score, $b$ tie there, and $s=K-a$ slots remain, uniform tie breaking includes a tied package with probability $s/b$. Inclusion probabilities above and below the boundary are one and zero. Independently randomizing each queue's ties gives
\begin{equation}
\mathbb{E}[|Q\cap Q'|]=\sum_{p\in P}\pi_p\pi'_p.
\label{eq:ties}
\end{equation}
This is combinatorial sensitivity, not a confidence interval.

We sweep $\alpha\in\{0,0.1,\ldots,1\}$ using each artifact's own maxima without outcome tuning. Spearman correlations use average ranks. Separately, we inventory incident-companion CSVs, count records and family identifiers, and compare recorded source timestamps with cutoffs. We do not repeat incident adjudication or authenticate the original registry responses.
